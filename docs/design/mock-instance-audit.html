What this mock decides, so the code has nothing left to invent.
  • Where. Settings → Administration, a tab beside Users / File providers / Outbox — the group that already means "instance, not tenant". No new navigation.
  • Row grammar is the org audit's, unchanged — dot, actor, action prose, monospace target, relative time, "Show more". One reader learns one shape; the panel earns no new vocabulary.
  • The dashed instance chip is the only new device, and it reuses the dashed grammar phases 4 and 5 gave to "a different KIND of thing" (a dormant binding, a delegated monitor). It says: these rows have no organization — not "the organization is missing".
  • A machine actor stays "machine", exactly as the org list renders a NULL actor: an audit row whose actor cannot be resolved must not silently borrow a human's name.
  • Nothing is deletable or editable here. An audit trail with a delete button is not one.
  • Not shown, on purpose: org-scoped rows. Mixing them in would make this the "everything" view and quietly answer a question this panel is not allowed to answer (who did what inside a tenant) for someone reading it in one glance.
