Body template Placeholders {{to}}, {{from}}, {{text}} are inserted as values, encoded for the content type. They must sit inside a JSON string or a form value.
FromCERBIX
Error code field(optional)error_code

The top-level key of the gateway's JSON response that holds its own error code. cerbix keeps that code (letters, digits, _ . -, up to 32) and never the response text, which can quote the number. Without it, a refusal is recorded as its HTTP status alone — a bad template and an empty balance then look the same. Any 2xx answer counts as sent: a gateway that reports failure inside a 200 is not supported, and a redirect is treated as a refusal.

1d · template refused a placeholder outside a value (§4.4); the server's 400 is shown under the field and under Save

Same rule, form body {{to}} is used as a field name. Placeholders can only be values: to={{to}}&text={{text}}.
