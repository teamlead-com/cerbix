The boundary is never renamed. These cells are UTC days. For a viewer at UTC+05 each begins at 05:00 their time, so the readout says so and never calls a cell their 31.08. Labelling a UTC bucket as a local calendar day is the same class of lie as F1 — spec §8.

§5.3 segments as lanes on the SAME axis — length is duration again, and a lane shows its own emptiness

Two mechanisms, two axes — deliberately not one rule. Inside a cell, height carries quantity, so a bad, unknown or excluded slice may be floored to stay visible (capped, presentation only, and never applied to provisional good time). Across the axis, width carries duration, so a lane is never floored and a sub-pixel segment gets a marker that says it is not to scale. The floor and the marker are not two flavours of the same fix.

Boundary marks cluster by the same rule as the lanes. The two definition transitions in this window are four minutes apart, so their marks land inside one pixel at any window zoom. Rather than a second convention for the same problem, the lane ruling is extended: cluster the events whose fixed marks collide; anchor the ONE non-geometric accent marker at the earliest real boundary, never at the cluster's midpoint; show the count with the exact local [first, last] extent and its numeric offset, with the UTC instants beneath; and list every revision in the cluster chronologically, because a count must not pretend to be one change. Why there is no line, and why the absence is drawn instead of left blank. Two designs for earning a stroke were proposed and both were wrong, the second on three readings of the tree: a run may occupy (retries+1) × timeout, result.allowed_skew bounds a clock test and not delivery, and job_issued_at is not a column of heartbeats at all. So two received heartbeats bound observed spacing and nothing more — queue wait is unbounded under broker trouble, leader absence leaves no trace, and cerbix cannot witness its own absence. Rather than leave that as whitespace, the observation ruler renders it positively: one tick per recorded check, and its emptiness is the picture of unobserved time. The — What would earn the stroke back is FR-032, a durable expected-run ledger — a reliability-data-model change with its own specification, not a line item here.

No threshold, deliberately. A fixed 12 CSS-pixel rule for marking gaps was specified and then withdrawn once the arithmetic was done: this panel runs at — px per minute, so 12 px would have marked all — intervals and told the six-minute hole apart from an ordinary minute not at all — and any threshold relative to the panel's own spacing would be a data-dependent selector, which is the inference this contract forbids. The ruler needs no threshold because it makes the same statement everywhere: a six-minute hole is 99 px of empty band and an ordinary minute is 16 px of empty band, and neither is called special.

One population, named. The header's avg and p95 and the dashed rule are all computed over the drawn series, not over a 24h window that happens to be a different set of checks. That is P3's fix: §6.3 allows either recomputing or labelling the other window's name, and this panel recomputes, so nothing on it describes a population it did not draw.

§6.3 the same panel when a check actually timed out — the timeout is now INSIDE the extent, so it is drawn

avg above p95 is not an error here. One 10-second timeout among sixty checks pulls the mean past the 95th percentile — which is exactly why the panel prints both and why the timeout gets its own line rather than being folded into a summary figure. Both numbers are computed from the drawn series.

A factual boundary, not a threshold. The timeout is stated in the header of both panels and drawn only when it falls inside the computed plot extent. No percentage decides it: a probe that times out is recorded at roughly the timeout (internal/prober/prober.go records elapsed latency on failure), so a real timeout raises the extent to include the line by itself.

The shape is the fix, and it is not the whole fix. A closed editor cannot hold a stale draft, which is why the Edit shape retires S2 by construction. But an open form is not a substitute for a draft-state model: the two P0 defects are invisible in any drawing, so they are stated here as acceptance criteria rather than pictured — (a) the context reset must cover the card's own draft, error and busy state and run before the next project's data renders, or a value typed for project A is saved into project B; (b) both writers must gate every assignment on the load generation they started under, as every neighbouring writer in that file already does. Visibility stops a stale draft being shown; the generation guard stops a stale response being written. They are complementary. Spec §7, D-0235 decision 11.
