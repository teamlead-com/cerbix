# iter-0005 — Default local login (username/password)

## 1. Summary

cerbix can now be used and administered without Keycloak. Added a built-in
username/password login with argon2id hashing, a config-driven bootstrap global admin, a
self-service password change, and store support for local (non-Keycloak) users. The auth
layer was refactored so OIDC is optional — cerbix runs OIDC-only, local-only, or both.
Verified end-to-end with the real binary in local-only mode. Closes FR-015; NFR-010 is
satisfied except rate limiting (deferred, D-0016).

- Canon: `project-description.md`, `status.md`, `decisions.md`, `iterations/iter-0004.md`.
- Spec: `specs/sec-authn-authz.md` (FR-015/NFR-010, added in iter-0004), decision D-0013.

## 3. What changed (by role)

### Agent A — Implementation
- Migration `00004_local_users.sql`: `users.keycloak_sub` NULLABLE + `password_hash` +
  partial unique email for local accounts.
- `store/users_local.go`: `CreateLocalUser`, `LocalCredentialByEmail`, `PasswordHashByID`,
  `SetPassword`, `CountUsers`; `scanUser` NULL-safe for `keycloak_sub`.
- `config`: `LocalAuthConfig` + validation (`local ⇒ database`, bootstrap password length,
  email required with password).
- `auth/password.go`: argon2id hash/verify (PHC, random salt, constant-time).
  `auth/local.go`: `LocalLoginHandler`, `EnsureBootstrapAdmin`. Refactored `auth.New` so
  OIDC is optional; `issueSession` helper; conditional `Routes`.
- `api`: `POST /api/v1/me/password` (+ `PasswordHashByID`/`SetPassword` on the API store,
  `minPasswordLen` on the handler).
- `cli`: build the authenticator when OIDC **or** local is enabled; run
  `EnsureBootstrapAdmin`.

### Agent B — Tests
- Hermetic: `auth/password_test.go` (hash/verify/salted/bad-format);

- DB-gated: `store_integration_test.go` `TestLocalUsersCoexistWithOIDC` (OIDC + local
  coexist, nullable `keycloak_sub`, credential lookup, password change, count).

### Agent C — Docs + Traceability
