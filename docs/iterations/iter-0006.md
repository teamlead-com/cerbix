# iter-0006 — SLA / SLI computation

## 1. Summary

cerbix now computes availability. Added SLI (uptime %) over rolling 24h/7d/30d/90d windows
per monitor and per project, SLO targets with error budgets, and first-class maintenance
windows that exclude heartbeats from SLA math. Exposed via authorized, tenant-isolated API
endpoints. SLI is computed by direct SQL aggregation over `heartbeats` (hermetic on any
Postgres); TimescaleDB rollups are a deferred optimization (D-0017). Verified full-stack
with the real binary. Closes FR-009 — the headline SLA/SLI requirement.
