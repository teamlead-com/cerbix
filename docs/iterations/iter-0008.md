# iter-0008 — Frontend scaffold (Docker, globex-style) + login

## 1. Summary

Stood up the Vue 3 + Vite + TypeScript + Tailwind frontend, built and served entirely in
Docker (no Node on the host), following the neighbouring `example/globex-frontend` structure:
a multi-stage image (node build → unprivileged nginx) that serves the SPA and proxies
`/api` and `/auth` to the cerbix backend. Design tokens from the approved mockups are wired
into Tailwind for both themes; the login screen is ported and connected to
`/auth/local/login` with an `/api/v1/me` session gate. Advances FR-011.

## 2. Input artifacts

- Approved design mockups + tokens: `docs/design/notes.md` (8 screens).
- `openapi.yaml` API contract (iter-0007).
- Reference conventions: `example/globex-frontend` (Docker layout, Vite/Tailwind/tsconfig, CI).
