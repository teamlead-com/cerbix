# iter-0009 — Frontend wired: API client, stores, shell, Dashboard & Monitor detail

## 1. Summary

Turned the scaffold into a working app: a typed API client generated from `openapi.yaml`,
a Pinia session store with a router auth guard, a reusable `AppShell`, shared UI components,
and the **Login**, **Dashboard**, and **Monitor detail** views wired to the real backend.
Verified end-to-end through the frontend nginx proxy — everything built and run in Docker,
no host Node. Advances FR-011.

## 2. Input artifacts

- Approved mockups + tokens (`docs/design/notes.md`), `openapi.yaml` contract.
- iter-0008 Docker frontend scaffold.

## 3. What changed (by role)

### Agent A — Implementation
- **API client:** `make gen-api` → `src/api/schema.d.ts` (openapi-typescript, container,
  repo-root mount); `src/api/client.ts` (`openapi-fetch`, `credentials: include`).
- **State/guard:** `src/stores/session.ts` (Pinia: `fetchMe`, `logout`, `isAuthed`,
  `isGlobalAdmin`, `initials`); router `beforeEach` guard (resolve `/me`, 401 → `/login`,
  redirect authed away from login); `LoginView` refreshes the session on success.
- **Shell + components:** `components/AppShell.vue` (sidebar + switcher + nav, topbar
  breadcrumb/theme/user, sign-out), `StatusPill`, `UptimeBar`, `Sparkline`, `MonitorCard`,
  `Kpi`.
- **Views:** `DashboardView` (orgs→project→monitors + project SLA → KPIs + monitor grid with
  per-monitor uptime/latency/heartbeat bars) and `MonitorDetailView` (SLA windows, latency
  chart, recent-checks table) wired to `/api/v1/*`.
- **Tokens:** added `*-weak` status tokens to `src/style.css` (both themes) and Tailwind
  (`bg-up-weak`, …) so components stay class-driven.

### Agent B — Tests / verification
- Frontend image build in Docker (`--network=host`): `vue-tsc` type-check + Vite build pass,
  bundle 105.85 kB (41.24 kB gzip), image `cerbix/frontend:iter9` 73.9 MB.
- **End-to-end** (Postgres + backend + the frontend nginx image, all Docker; requests driven
  through `localhost:8000` = the frontend proxy):
  - `GET /` → SPA 200; `POST /auth/local/login` → `{"ok":true}` + cookie; `GET /api/v1/me`
    → the bootstrap admin (`is_global_admin: true`).
  - Created org/project/self-check monitor via the proxy; the pipeline drove it to
    `status: "up"` — `30d` SLA `total 3 / up 3 / 100%`, heartbeats `up: true`.
  - `GET /api/v1/me` with no cookie → `401` (guard's redirect path).

### Agent C — Docs
- `docs/design/notes.md` (iter-0009 section), `docs/status.md` (FR-011 evidence), this report.

### Agent D — Ops
- `make gen-api` fixed to mount the repo root so `../openapi.yaml` is reachable in the
  container. Everything (types, build, run, e2e) via Docker.
