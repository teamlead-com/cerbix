# iter-0050 — Global silence until

## 1. Summary

Seventh slice of the audit-gap package (mockup approved). The backend honored
`global_silence.until` (auto-expiring silence, evaluated at delivery time) but the UI
could not set it — and worse, saving the toggle sent `{enabled}` only, silently wiping
an `until` that had been set via the API.

## 2. What was done

Settings → Administration → Alerting: when the silence toggle is on, an optional
**Until** (`datetime-local`) appears; the banner shows the auto-resume moment. The save
round-trips the full `{enabled, until}` object (data-loss fixed), converting between
the input's zone-less local time and the API's RFC 3339.

## 3. Verification

vue-tsc build green. API E2E: PUT with until → GET returns it unchanged; toggling off
and on preserves the semantics. Browser E2E: field appears with the toggle, setting a
date updates the banner ("silenced instance-wide until …"). Dev instance left with
silence off.
