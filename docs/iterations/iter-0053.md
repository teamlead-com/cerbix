# iter-0053 — Agent tokens UI

## 1. Summary

Tenth slice of the audit-gap package (mockup approved): the pull-agent token API
(`GET/POST /api/v1/agent-tokens`, `DELETE /api/v1/agent-tokens/{tokenID}`, global admin)
was fully built and spec'd with zero UI — issuing or revoking a token for a broker-less
region required curl.

## 2. What was done

New Settings → Administration → **Agent tokens** tab (`AgentTokensPanel.vue`,
self-loading panel pattern): list (name/region/created/status; revoked rows stay,
dimmed, with a "revoked <date>" pill), issue form (name + region), the plaintext secret
shown once in a banner with Copy — the same contract as API tokens — plus a hint to put
it into the agent's `pull.token`. Revoke per active row. No backend changes.

## 3. Verification

vue-tsc build green. Live E2E: issue → "shown once" banner + row appears → revoke →
"revoked" pill; the 403 fallback message covers non-admins (tab is admin-only anyway).
