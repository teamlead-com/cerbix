# iter-0056 — Feed links that work for non-public pages

## 1. Summary

Second slice of package 2. The RSS/Atom/JSON links in both the status-page editor and
the page itself hardcoded the public slug URL, which 404s for `internal` pages and for
`unlisted` without a token. The authed `GET /status-pages/{pageID}/feed` — built for
exactly this — was never called by the SPA. No mockup: the change is link targets only.

## 2. What was done

- `StatusPagesView.feedHref()` mirrors the page-preview logic: internal → authed feed
  endpoint by page id; unlisted → public URL with `&token=`; public → unchanged.
- `PublicStatusView.feed()` uses the authed endpoint in internal-preview mode
  (`?preview=<id>`), keeping the existing token handling for unlisted.

## 3. Verification

vue-tsc green. Live E2E: authed feed returns 200 with a session and 401 anonymously —
nothing leaks; the public path stays intact for public pages.
