# iter-0057 — Audit log paging

## 1. Summary

Third slice of package 2 (mockup approved): the Members audit list hardcoded
`limit: 30` with no indication more rows exist — "who removed that member last month"
was silently unanswerable, although the backend accepts any limit up to 500.

## 2. What was done

`MembersPanel`: the window widens on demand — a "Show more (N shown)" button under the
list steps 30 → 100 → 500 (the backend cap) and disappears when the response no longer
fills the window (or the cap is reached).

## 3. Verification

vue-tsc green. Live check: the widened limit reaches the API (`?limit=500` returns the
full history); with fewer rows than the window the button does not render.
