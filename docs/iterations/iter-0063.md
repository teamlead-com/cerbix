# iter-0063…0066 — E2E coverage expansion (one report: pure test infrastructure)

## 1. Summary

`func-e2e-coverage`: the base suite (23 tests, D-0124) grows to **34 tests** toward real
feature coverage. No product code changed; one dev-compose sidecar added.

## 2. What was done

- **iter-0063 (cheap wins)**: `alertmanager.spec` — firing opens an incident correlated
  by fingerprint (idempotent re-fire, external_key chip rendered, resolved closes);
  `sla.spec` — inline objective editing on the SLA page + burn-rules round-trip;
  `outbox.spec` — dead-letter surface smoke.
- **iter-0064 (probers against the stack itself)**: `probers.spec` — http monitor with
  a conditions expression probes cerbix's own `/healthz` and goes up; a failing
  condition takes it down; test-connection probes postgres/rabbitmq instantly (the
  ghost-region check is transport-aware: 502 over AMQP/pull, success on the inproc
  dev dispatcher); composite **quorum** flips with M over live children.
- **iter-0065 (mail flows)**: Mailpit sidecar in the dev compose (profile `mail`,
  10.5.0.15, :8025 UI/API + :1025 SMTP). `mail.spec` switches SMTP settings to the
  sidecar (auth cleared — Go's smtp refuses PlainAuth over plaintext) and walks:
  password reset request → letter → confirm → the new password signs in → restored;
  status-page subscribe → letter → the confirm link opened in a real browser page
  (the SPA performs the confirmation) → `confirmed_at` set. Skips cleanly without
  the profile.
- **iter-0066 (time-based)**: `timeflows.spec` — confirm-phase acceleration measured
  live (interval 60s / threshold 3 / confirm 5s → down in ~25s instead of ~3min);
  full TOTP lifecycle with RFC 6238 implemented in the test (enroll → enable →
  password-only login 401 `totp_required` → password+code logs in → disable).
