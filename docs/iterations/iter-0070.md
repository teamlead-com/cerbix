# iter-0070 — SSE silent-death watchdog

## 1. Summary

First slice of `func-transport-resilience`. The SSE keepalive was an SSE *comment* —
proxies saw it, the browser's EventSource API never did — so a socket dying without an
error event (the classic mobile Wi-Fi → LTE switch) left the dashboard silently frozen,
and a naive client watchdog would have flapped on every healthy-quiet system.

## 2. What was done

- Server: the 25s keepalive becomes a real `event: ping` (`data: {}`) — same
  proxy-keepalive effect, now visible to the client.
- Client (`stores/live.ts`): `lastSeen` stamps on open/status/ping; a 10s watchdog
  recreates the EventSource after >75s of silence (two missed pings). `started` stays
  true through the recreation, so the header's "Live updates reconnecting…" chip shows
  until the new connection opens; the watchdog interval is cleared on `disconnect()`.

## 3. Verification

`curl -N` on the stream shows `event: ping` within the first cycle; vue-tsc + go build
green; live stack redeployed.
