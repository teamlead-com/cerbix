# iter-0082 — Remaining correctness sweep

## 1. Summary

Eleventh and final `func-hardening` slice — a grab-bag of eight correctness/robustness
items. Two needed no change; six were fixed.

**No change:**
- **SSE `WriteTimeout`** — `httpsrv` sets only `ReadTimeout`, leaving `WriteTimeout` unset;
  that's the correct config for long-lived SSE streams.
- **SSE filter-before-buffer** — filtering already happens before *emission*
  (`handlers_events.go` checks the subscriber's visible projects before writing), so there
  is no cross-tenant leak. Pushing the filter before *buffering* is a memory optimization
  (a noisy tenant can fill a 32-slot channel), not a correctness/security bug — deferred to
  avoid a broad `Subscribe` signature refactor with no security payoff.

## 2. What was fixed

1. **Push `failure_threshold` pinned to 1** (`domain.Monitor.Normalize`). A push
   dead-man's-switch timeout is a single definitive signal, but the timeout was recorded as
   a normal down heartbeat through the confirmation-gated status machine, so a threshold of
   N delayed "down" by ≈ N × interval. Push monitors now normalize `FailureThreshold` to 1.
2. **ICMP echo id/seq/payload match** (`prober/icmp.go`). The read loop accepted any
   `EchoReply`, so a concurrent ping or stray reply on a shared raw socket read as a false
   "up". It now sends a random per-probe seq + 16-byte payload and only accepts a reply
   whose seq+payload match (and id, on the raw socket where we own it). Extracted
   `echoReplyMatches` for testing.
3. **SSRF CGNAT block** (`prober/guard.go`). `100.64.0.0/10` (RFC 6598) is neither
   `net.IP.IsPrivate()` nor non-global-unicast, so it fell through to "public". Added an
   explicit `isCGNAT` check gated by `allow_private_ips`.
4. **OIDC bounded client + off boot path** (`auth/auth.go`, `auth/handlers.go`). Discovery,
   JWKS, and token exchange used `http.DefaultClient` (zero timeout), and the first
   `SyncOIDC` ran synchronously before the HTTP server started — a hung IdP could block boot
   forever. A 15s-bounded client is injected via `oidc.ClientContext` (and stored for the
   token exchange), and the first sync moved into the reloader goroutine.
5. **Shutdown goroutine drain** (`cli/cli.go`). Background workers (outbox, ingest,
   scheduler, worker, LISTEN notifiers) were `go X.Run(ctx)` fire-and-forget; shutdown only
   awaited `srv.Shutdown`. A `sync.WaitGroup` now drains them (10s-bounded) after ctx
   cancel, before the process exits.
6. **Unique-slug 409 + FK existence oracle** (`store` + `api`). `CreateOrganization`/
   `CreateProject` map a 23505 unique violation to `store.ErrConflict` → 409 (was a raw
   500). `monitorInOrg` now returns an identical "monitor not found" for a wrong-org id as
   for a nonexistent one, so a caller can't enumerate cross-tenant monitor ids. (The
   add-member-by-email "must sign in first" message is left as an accepted UX affordance.)

## 3. Verification

- `domain` push-threshold pin; `prober.TestCheckIP` CGNAT cases (blocked without private,
  allowed with, boundary 100.128 public); `prober.TestEchoReplyMatches` (own reply matches
  raw+udp, wrong seq/payload/foreign-id rejected, udp ignores id, non-reply rejected);
  `api.TestDuplicateSlugConflict` (409 org+project, fresh slug 201);
  `api.TestComponentAuthzAndMonitorOrgCheck` (cross-org and missing responses byte-identical).
- Full `-race` suite green; `go build`/`vet` clean; image rebuilt; **E2E 34/34**.
- **Live**: a `stop` showed `shutdown_signal_received` → `stopped` with no
  `background_drain_timeout` — the goroutines drained cleanly.

## 4. Deferred

SSE filter-before-buffer (optimization, no leak) — noted for a future perf pass; the
add-member-by-email existence hint — accepted UX for org admins.
