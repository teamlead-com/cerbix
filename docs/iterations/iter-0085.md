## 4. Decisions captured

- Native `format: 1` ProjectBundle; no Kubernetes `apiVersion`/`kind` envelope.
- Existing org/project prerequisite; no tenant provisioning from monitor YAML.
- One file/one project bundle; atomic/fault isolation per resolved project.
- Object-level provider ownership; UI/API monitors coexist and remain untouched.
- Invalid bundle retains LKG; ambiguous invalid scan suspends orphaning.
- Valid absence orphan/disables after grace; never automatic hard delete.
- Canonical semantic no-op performs no monitor write/revision bump.
- Provider runs in `api`/`all`, advisory-elected per provider; no controller role.
- P0b `execution_revision` is a production prerequisite.
- Inline secrets/environment expansion are forbidden.
