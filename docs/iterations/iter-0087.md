# iter-0087 — Monitoring as Code: contract foundation (FR-017/NFR-014, phase 1)

## 1. Summary

First implementation slice of the file provider (spec `func-monitoring-as-code` §20.1):
strict static `providers.file` configuration and a pure `internal/fileprovider` contract
layer — ProjectBundle decode, canonicalization, validation, and deterministic planning —
with **no** database or filesystem-watch work. Everything here is unit-testable in memory.

P0b prerequisite was re-verified against code (not docs) before starting: migration 00055
`execution_revision`; scheduler dispatches `dispatch.CheckJob{Monitor: m}` carrying the
revision; prober stamps it into every heartbeat (`prober.go:98/110/121`); ingest →
`RecordScheduledResult` applies the gate under `FOR UPDATE` before insert; `UpdateMonitor`
bumps it; `TestRevisionGate`/`TestRecordDeadmanResult` green. P0b is DONE — no unsafe
fallback needed; the reconciler (iter-0088) will use the D-0142 `UpdateMonitor` contract.

FR-017/NFR-014 move `TODO → IN_PROGRESS`. They remain not-DONE until every §19 acceptance
criterion is delivered.

## 3. Mandatory role outputs

### Agent A — Implementation

- `internal/config/providers.go`: `ProvidersConfig`/`FileProviderConfig`/`ProviderScopeConfig`/
  `ProviderLimits`; `normalizeProviders` (per-entry defaults applied after decode) wired into
  `Parse`; `validateProviders` (name regex, ≤64 providers, absolute non-root directory,
  scope matrix, duration bounds, positive+bounded limits, overlapping-root rejection) wired
  into `Validate`. Structural only — the directory-exists + DB checks are role-specific
  (`api`/`all`) startup wiring, deferred so `scheduler`/`worker`/`agent` parse the same config.
- `internal/fileprovider` pure contract layer: `Decode(bytes, scope) → DesiredProject`
  (strict `KnownFields`, single-document, duplicate-key detection, format-1, scope→tenant
  matrix §5, per-monitor build with format-1 defaults + domain `Normalize`/`Validate`,
  duration→whole-seconds, inline-secret and unsupported-type/field rejection); `canonicalHash`
  (§7 semantic hash: excludes comments/order/path/server fields; sets sorted+deduped;
  conditions order-preserved); `checkDependencyDAG` (self/missing/cycle); `Plan(desired,
  current) → ProjectPlan` (pure deterministic action set + immutable-type guard, UID-sorted
  for stable lock order).
- No runtime apply, watcher, metrics, or DB — those are iter-0088+. No `controller` role.

### Agent B — Tests
