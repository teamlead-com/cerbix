## 2. Changes

1. **Named-provider source filter — UI (§15).** `frontend/src/views/MonitorsView.vue`: the
   source filter is now `All / UI / <one entry per named file provider>` (value
   `all|ui|file:<provider>`) instead of a single generic `file` bucket, so multiple providers
   are individually selectable — the §15 "filter by source (All, UI, named provider)" contract.
2. **Named-provider filter — diagnostics API (§15).** `internal/api/handlers_fileproviders.go`:
   `GET /api/v1/admin/file-providers?provider=<name>` narrows BOTH `bundles` and the runtime
   `providers` list to one provider. OpenAPI + TS schema updated. Test:
   `api.TestFileProviderDiagnostics` extended (provider=platform keeps all platform rows;
   provider=nope matches nothing).
3. **Doc-drift scrub.** `docs/runbook.md`: documented the diagnostics API response shape
   (`{bundles,providers}`, process-local leadership, `?provider=`, org-scoped `{bundles}`) and
   corrected the smoke description to the full lifecycle.
4. **gofmt fix.** `internal/api/api.go` struct-field comment alignment (regression from the
   iter-0101 `fpStatus` field) reformatted.

  enhancement (would need an approved UI mock first, per the docs process).

  remain out of the v1 file schema (spec §3.1), by design.
