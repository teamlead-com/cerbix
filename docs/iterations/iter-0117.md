## 3. Delivered

- One idempotent serve cleanup owns normal and fail-fast exits: root cancellation, bounded
  tracked-goroutine drain, dispatcher close, then Store close. Settings and OIDC refreshers no
  longer hide internal goroutines; the pull agent is also bounded on exit.
- The distributed `api` service mounts the configured Monitoring-as-Code root exactly like
  `--role all`. A config-correlated Compose test checks both owners and excludes scheduler/worker.
- File-provider diagnostics always encode required collection fields as JSON arrays, including
  no-runtime-source and named-filter-to-empty cases. OpenAPI, generated TypeScript, unit and
  browser assertions agree.
- The repository's 42 recorded lint findings were removed without weakening `.golangci.yml` or
  secret-column policy. Output/close/rollback handling is explicit and metrics rendering stops
  after its first writer failure.
- RabbitMQ 4.3 compatibility is real but operationally fenced: test queues are shared
  durable+auto-delete, initial consumers form a startup barrier, and mandatory RPC publish fails
  promptly when a region queue is absent. The live test covers v1/v2 jobs and v1/v2 test RPCs.
  Compose requires a persisted image selector (fresh templates pin 4.3); D-0157/runbook forbid
  both direct data-directory jumps and accidental downgrade, and specify the application
  queue-shape migration, offline snapshots, broker hops and rollback rules.
- The frontend lockfile carries the smallest transitive patch update needed to remove the audit
  finding (`@redocly/openapi-core` 1.34.19 / `js-yaml` 4.3.1).
