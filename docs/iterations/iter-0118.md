# iter-0118 — Non-production stack Make facade

Status: **DONE**.

## 1. Scope

Provide safe, memorable Make entrypoints for building, starting, checking, and testing the
repository's non-production single-process, distributed-role, and geo topologies. Production
Compose and the RabbitMQ retained-volume upgrade procedure remain operator-explicit and outside
the Make facade.

## 3. Agent role outputs

### Agent A — Implementation

- Added fixed, non-production-only targets for base single-process, base distributed-role,
  geo-central, and geo-all topologies. Existing native `build`, `test`, `race`, and `lint`
  targets keep their meaning.
- Startup is serialized as image build → healthy infrastructure → one explicit migration →
  role processes → per-role `/readyz`. Readiness for unpublished roles runs inside their fixed
  Docker networks.
- Base and geo use independent mandatory env pins. `dev-init`/`geo-init` refuse both overwrite and
  initialization over a retained RabbitMQ volume. Compose and env paths, including the Compose
  executable, are not caller-overridable. The command also drops a hostile shell image override
  and pins the Compose project name, keeping each retained volume bound to its persisted env file.
- Topology guards query Docker project/service labels without requiring the other topology's env;
  inspection errors fail closed. Teardown omits `-v`, `--volumes`, pruning, and
  `--remove-orphans`.

### Agent B — Tests

- Added static contract, expanded `make -n`, exact geo-network-set, image-pin, migration-order,
  URL, guard, and destructive-operation regressions in `internal/cli/compose_wiring_test.go`.
- Made the browser harness deterministic on a fresh DB: exact `e2e-harness` tenant, exact
  Keycloak fixture user, cleanup in `finally`, committed lockfile, quoted argv, mapped host UID,
  ephemeral dependency/auth mounts, and persisted failure artifacts.
- Made topology selection explicit: single excludes the geo-only spec, ghost-region behavior is
  exact (`200` in-process, `502` distributed/geo), and the single Make gate requires Keycloak and
  Mailpit rather than silently skipping them.
- Added geo RPC and scheduled-path coverage for both the AMQP worker and HTTP-pull agent; parsed
  Compose tests assert their exact isolated network memberships.

### Agent C — Docs + Traceability

- Added D-0158 and synchronized status, traceability, README, onboarding, contributor/agent
  guidance, overview, E2E spec, OIDC ops spec, Compose comments, and the file-provider example.
- Documented that the default browser suite has one conditional MaC UI assertion; the independent
  `e2e/mac-smoke.sh` remains the authoritative managed-bundle lifecycle proof.

### Agent D — Observability + Ops

- Kept the live contract on existing `/readyz` rather than adding duplicate health signals.
- Preserved D-0157 as a raw operator procedure: the Make facade never upgrades RabbitMQ. Base and
  geo pins map one-to-one to different named volumes and can sit at different upgrade checkpoints;
  the runbook carries explicit per-hop command surfaces for both.
- Verified topology conflicts fail before state mutation and every down path preserves named data
  volumes.
