# iter-0122 — Round-2 corrections to iter-0121, and its governance disposition (FR-020/NFR-015)

## 1. Summary

Two things, and the second is why this report exists rather than an edit.

**Product.** The independent round-2 review of [iter-0121](iter-0121.md) found three
defects, all cases where the previous commit's claim was broader than what it implemented:
a partial PATCH preserved only an INLINE credential (a ref-based monitor answered an
ordinary edit with a 500), "persistent, not first" readiness existed on one executor path
out of four, and a skipped monitor was still on the failure control path after only its
metric had been fixed. All three are fixed in `01dd9fa`.

**Governance.** iter-0121 was written and declared closed without the structure AGENTS.md
requires — a 3–8 task plan ordered P0→P1→P2, the Agent A/B/C/D role outputs, and atomic
`status.md` items — and `docs/status.md` was never touched for it. It also carried two
close-out claims that its own follow-up review then falsified: that the audit remainder was
"closed entirely", and that the P1s were done. Iteration reports are immutable after close,
so iter-0121 stands as written and this report is its correction — the same disposition
iter-0114 applied to iter-0113. **What iter-0121 says about its own completeness should be
read as superseded here; its technical content stands.**

## 4. Why the suite did not catch these

Continuing iter-0119 §5, because the pattern is the transferable part.

- **The preservation test seeded only an inline credential.** It exercised the branch that
  worked and never the branch that returned an internal error. A regression covering one of
  two shapes is not coverage of the rule; it is coverage of an example.
- **The readiness change was applied where the review pointed, not where the contract
  applied.** Three other paths — worker jobs, worker test-RPC, and the agent's
  `unknown_key_id` — kept the old behaviour, and one of them had a test actively pinning it.
  A rule that lives in four places has four chances to be half-changed, which is why it now
  lives in one.
- **The skip fix was made to the metric because the metric was what the finding named.** The
  warning, the failure counter and the backoff all still treated it as an error, and no test
  asserted the metric at all, so reverting the single condition left everything green.
