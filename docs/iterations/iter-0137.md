## 3. Changes

**P1-1 — the gate is authoritative ([152] §1, items 1–4).**
- `retention.go`: `adoptionPolicy{fenceBudget, rowGate}` splits the automatic cadence from
  the operator mode over ONE implementation (`adoptServiceFactMonth`); the row gate runs as
  an unlocked preflight (cheap refusal, no parent lock) AND is re-counted UNDER the parent's
  ACCESS EXCLUSIVE lock before the sweep — the unlocked count alone was a TOCTOU. A refusal
  under the lock rolls back; bounded damage is the lock-queue wait, never the oversize DELETE.
- **Operator artifact shipped**: `cerbix adopt-fact-month --config <path> --month YYYY-MM
  [--timeout 10m]` (`cli.go` + `Store.AdoptServiceFactMonthOperator`) — same code path,
  operator budget, gate off, validated `YYYY-MM` input normalized to the UTC month, idempotent
  rerun. It covers BOTH operator cases: oversize, and persistent under-bound fence failure
  after quiescence (a row count is not a wall-clock guarantee). The runbook's placeholder psql
  procedure is DELETED.
- **Ownership**: spec amendment §10.11 (additive, provenance-marked) + decision D-0161. The
  refusal message names the command. `serviceFactPartitionName` is now the single spelling of
  the partition name across creators, probes and the command.

**P1-2 — FK verification by complete definition ([152] §2).**
- `ensureStagingLifecycle` judges reserved-named constraints by contype, `convalidated`,
  BOTH column-name arrays in declared order (`conkey`/`confkey` joined to `pg_attribute`),
  referenced relation, `confdeltype`, `confupdtype`, `confmatchtype`, `condeferrable` AND
  `condeferred`. Every reserved-name non-exact row — including an unvalidated key of the
  correct shape — counts as a squatter and fails closed.

**P2 — honest evidence harness ([152] §3).**
- The fresh-migration UTC probe uses a unique per-run database
  (`cerbix_test_utcprobe_<pid>_<nanos>`) derived from the PARSED gate DSN, never pre-drops
  anything, drops only what it created, and FAILS (not skips) on privilege errors — inside
  the configured DB gate this evidence is mandatory.
