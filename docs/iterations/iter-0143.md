## 3. Changes

The increment since [201]/[203] is FRONTEND + DOCS ONLY (no Go/SQL/OpenAPI byte changes):
- **`frontend/src/lib/objective.ts`** — `canonicalObjective`, the client mirror of
  `domain.CanonicalObjective`: non-finite rejected; raw judged in the open (0,100) first
  (100.00004 rejected as typed); half-up rounding at four decimals (`Math.round` is
  half-away-from-zero, coinciding with Go's `math.Round` on the positive values the raw
  bound admits); the canonical result must stay inside (0,100). One exported helper — the
  same one-rule structure as the Go side.
- **`SlaView.vue`** — `saveSlo` canonicalizes through the helper: 99.99995 and 0.00001 are
  rejected ON the client with the existing error text and NO request; the CANONICAL value is
  what the PUT carries, so what the user confirmed and what the server stores are the same
  number.

## 4. Tests
