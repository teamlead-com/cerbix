# iter-0149 — two honesty fixes the owner's own screenshot surfaced

Status: DONE
Scope: no feature work. Two things the product was saying that were not true, both found by
looking at the running stack rather than at the code.

## 1. The services list claimed phase 2 had not shipped

`ServicesView.vue` closed with "Availability, error budget and burn rate **arrive with the next
iteration**". That was written for phase 1 and became false at iter-0140: phase 2 shipped all
three, and they were visible on the service page RIGHT NEXT to the list making the claim.

This is the exact defect class FR-021 exists to prevent — a confident statement about what the
product knows, left unmaintained until it lied. The replacement says where the numbers live and
when they appear, and keeps the one honest fact the list is built on: it shows the WATERMARK,
because `sealed_through` cannot flatter a service that stopped materializing.

Change: [`frontend/src/views/ServicesView.vue`](../../frontend/src/views/ServicesView.vue) — the
closing note, with a comment tying it to the mock rule so the next phase has to keep it true.

## 2. The committed SPA snapshot was three weeks stale — and nothing could have noticed

`internal/web/dist` is embedded by `go:embed`, so it is what `go build` and
`go install .../cmd/cerbix@latest` serve. The Docker image builds the SPA itself and
`rm -rf`s that directory before embedding (`docker/Dockerfile:23-25`), so:

- every `make dev-*` path is correct no matter how stale the snapshot is;
- therefore no gate, test or e2e run could ever fail because of it;
- and the snapshot last moved on 2026-08-11 (`6749bd1`) — it contained neither phase 2 nor
  phase 3. `go install` from a clean checkout served a three-week-old UI.

**Root cause, not symptom:** refreshing it was a manual step with NO command. Fixing only the
bytes would leave the same trap for the next change.

Changes:
- [`Makefile`](../../Makefile): new `spa-snapshot` target — build the SPA in the pinned node
  container, replace `internal/web/dist`, and restore `assets/placeholder.txt`, which is a
  FIXTURE (`internal/web/web_test.go` asserts the embedded asset route through it), not build
  output. Registered in `.PHONY`.
- `internal/web/dist/**`: the snapshot refreshed by that target (50 files) — now carries phases
  2 and 3.
- [`CLAUDE.md`](../../CLAUDE.md): the frontend section now states the rule, so the next frontend
  change runs the target instead of rediscovering the trap.
