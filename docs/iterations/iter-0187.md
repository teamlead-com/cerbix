## Delivered behavior

The implemented path is organization → project → monitor → first persisted heartbeat. Progress is
recomputed from tenant-scoped server facts on every load. The guide is inline and non-blocking; normal
routes remain available. `Skip for now` closes the current presentation, while `Do not show
automatically` stores only `1` under a user/scope-local key. A first UP or DOWN result completes the
journey; DOWN remains visibly failed. Optional services, notifications, status pages and reliability
objectives stay outside the four-step denominator.

Existing installations are not disrupted: their normal Dashboard opens with the same four KPIs,
90-day availability and monitor cards. Manual `Get started` inserts a compact collapsible panel above
that content. Monitor creation still belongs to the existing typed form, and push tokens remain on the
monitor detail page. Failed reads are never rendered as empty tenants.
