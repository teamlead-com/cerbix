## Goal

Prevent the status-page hero from presenting a green all-clear while active incidents remain open,
without turning incident lifecycle into a second component-health calculation.

## Agent A — Implementation

- [`statuspage.ts`](../../frontend/src/lib/statuspage.ts) now owns one pure
  `overallStatusPresentation` composition over `summary`, `summary_state`, `unmeasured_count`, and
  `active_incidents[].impact`. It returns headline, supporting copy, visual semantics, icon type,
  active count, worst impact, and the corresponding existing token classes.
- Worst impact is total and order-independent: `critical > major > minor > none`. With no active
  incidents, the existing component-only hero meaning remains unchanged. Measured impairment or
  maintenance keeps headline precedence; otherwise active incidents lead with their count.
- [`PublicStatusView.vue`](../../frontend/src/views/PublicStatusView.vue) consumes that one result for
  both public and authenticated-preview rendering. Duplicate headline/subline/band/icon branches were
  removed from the component. Component rows, uptime strips, incident lifecycle, maintenance, SLA/SLO,
  feeds, webhooks and the existing hero timestamp are unchanged.

## Agent B — Tests

- [`statuspageOverall.spec.ts`](../../frontend/src/lib/statuspageOverall.spec.ts) provides a
  table-driven 13-test matrix for operational, impaired, maintenance, no-data, empty, unmeasured,
  zero/one/many incidents, all four impacts, recent/resolved exclusion and array permutation.
- [`PublicStatusView.spec.ts`](../../frontend/src/views/PublicStatusView.spec.ts) kills restoration of
  the exact all-clear phrase, green band or check icon; pins impairment headline precedence; requires
  an accessible `h1`; and proves public/preview composition parity for identical facts.
- [`statuspages.spec.ts`](../../e2e/tests/statuspages.spec.ts) creates an isolated project with one
  operational manual component, one unmeasured incident-bound component, and one active Major
  incident. Public and authenticated preview match on desktop and 430 px, expose complete textual
  content, remain non-green with an alert icon, and have no horizontal overflow.
