## Source

`.github/workflows/security.yml` had been failing on `main` since 2026-10-08 (the last green run; 26
failures in a row by 2026-11-02, nightly and on push). Two jobs failed, the secret scan passed. Read
from run `41432126584`:

1. **Go vulnerabilities (call-graph)** — `govulncheck` v1.7.0 on the go.mod toolchain (Go 1.25.13):
   13 vulnerabilities with call paths from cerbix's code, all in the standard library (`net/http`,
   `net/http/internal/http2`, `crypto/tls`, `crypto/x509`, `html/template`, `net/textproto`), four of
   them also in `golang.org/x/net` v0.58.0. Example call paths from the run:
   `internal/prober/websocket.go` (`websocketProber.Probe` → `tls.Conn.HandshakeContext` →
   `x509.Certificate.Verify`), `internal/dispatch/amqp.go` (`AMQP.ServeTests` → `http2.Framer.*`).
2. **Frontend dependencies** — `npm audit --omit=dev --audit-level=high`: one high-severity set in
   `vite` 8.2.0–8.2.2 and `launch-editor`. `vite` is a devDependency, but `vue-router` 5 depends on it,
   so it is in the production tree.
